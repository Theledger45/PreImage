# PreImage

PreImage is a lightweight demo workspace for iterating on article and catalog-style preview layouts before wiring into a larger product.

## What is included

- `demos/editorial-demo.html`: Editorial demo using shared rendering helpers.
- `demos/remaining-demos.html`: Remaining demo backlog in a compact catalog view.
- `demos/lib/`: Shared UI and rendering helpers.
- `docs/demo-plan.md`: Work-order sequence and local run notes.

## Local preview

```bash
python -m http.server 4173
```

Then open the HTML files above in your browser.
